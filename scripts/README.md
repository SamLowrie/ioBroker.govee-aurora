# Optional scripts

This directory contains optional tools and examples. They are **not** loaded,
installed, or executed by the Govee Aurora adapter. Use them manually when
their purpose matches your setup.

| Directory | Contents |
| --- | --- |
| [`decode/`](decode/) | Read-only Python tools for downloading Tap-to-Run payloads and investigating the H6093 protocol. |
| [`ioBroker/`](ioBroker/) | JavaScript-adapter examples that must be copied manually into ioBroker's Scripts tab. |

Each subdirectory has its own README with requirements, installation, and
usage notes. Do not copy extracted personal scene files, passwords, or bearer
tokens into a public repository.
